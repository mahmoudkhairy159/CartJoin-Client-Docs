---
title: "حل المشكلات والتصعيد"
description: "تشخيص الحالة قبل التكرار."
---

| العرض | الإجراء |
|---|---|
| قائمة غير ظاهرة | تحقق من نوع اللوحة والدور، واطلب من مالك الصلاحيات مراجعتها |
| لم يوجد السجل | تحقق من الرابط والملكية ومساحة العمل؛ لا تحاول معرفات متاجر أخرى |
| انتهت الجلسة | سجل الدخول بنفس نوع الحساب ثم أعد فتح السجل |
| فشل حقل | صحح الحقل المسمى؛ القيم المرجعية يجب أن تتبع النطاق الحالي |
| تغير السعر أو المخزون | أعد تحميل السلة وراجع المتغير والكمية والإجمالي |
| الدفع غير مؤكد | افحص المحاولة وإثبات التحويل أو حدث المزود؛ لا تعتمد صفحة الرجوع |
| مهلة بعد إرسال مالي | افحص الفاتورة والسجل والمرجع الخارجي قبل إعادة المحاولة |
| تصدير غير جاهز | تابع حالة المهمة؛ الطابور ليس ملفاً مكتملاً |
| المؤشرات صفر مع وجود طلبات | راجع الفترة وتعريف المقياس ووقت التحديث |
| لا توجد مساحة بائع | راجع اعتماد علاقة البائع بالمتجر وحالة الحساب |

عند التصعيد أرسل الدور والمتجر ومعرف السجل والتوقيت والخطوات ورسالة الخطأ. استخدم تذكرة خاصة للدليل اللازم فقط، دون كلمات مرور أو رموز وصول أو تفاصيل دفع كاملة.
