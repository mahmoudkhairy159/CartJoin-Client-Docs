## مسارات الشراء والعمليات

تبدأ مسارات العميل بـ `/api/user/v1` ومسارات المتجر بـ `/api/tenant/v1` ومسارات المنصة بـ `/api/admin/v1`.

| الواجهة | الطرق وأجزاء المسار |
|---|---|
| العميل | GET `gift-card-offers` وGET/POST `gift-card-purchases` وGET `gift-card-purchases/{publicId}` |
| سلة العميل | POST `cart/gift-cards` مع `code` أو `public_id` لبطاقة مرتبطة بالحساب و`requested_amount` اختياريًا. DELETE `cart/gift-cards/{applicationId}`. تعرض السلة وعروض الشحن المراجع المخفية والقيمة المطبقة و`external_payment_due`. يقبل إتمام الطلب `quoted_external_payment_due` لحماية القيمة التي راجعها العميل. |
| الشراء في المتجر | GET/POST `gift-card-offers` وPUT `gift-card-offers/{publicId}` وGET `gift-card-purchases` أو `gift-card-purchases/{publicId}` وPOST `gift-card-purchases/{publicId}/chargeback-review` |
| موظفو المتجر | POST `gift-cards/{publicId}/resume` وGET `gift-card-approvals` وPOST `gift-card-approvals/{publicId}/{approve-or-reject}` وGET/POST `gift-cards/{publicId}/deliveries` |
| المنصة والمتجر | GET/POST `gift-card-reconciliation-runs` وGET `gift-card-reconciliation-runs/{publicId}` وGET `gift-card-reconciliation-cases` أو `gift-card-security-cases` وتفاصيلهما بالمعرف العام |
| أوامر الحالات | POST `gift-card-reconciliation-cases/{publicId}/{action}` للتعيين أو إعادة الفحص أو التحقق أو الحل أو الاستبعاد، وPOST `gift-card-security-cases/{publicId}/{action}` للتعيين أو تأكيد الاستلام أو التحقيق أو الحل أو الاستبعاد. يمكن للموظف المخول تعليق البطاقة أو استئنافها من حالة الأمان. |
| صادرات المتجر | POST/GET `gift-card-exports` وGET `gift-card-exports/{publicId}` أو `gift-card-exports/{publicId}/download` |
