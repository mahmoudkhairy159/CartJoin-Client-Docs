## خطوات الاستخدام

راجع مؤسسة البائع ومستنداتها، ثم افتح ارتباطات البائعين بالمتجر وحالة الموافقة. يسجل البائع الدخول ويختار مساحة عمل معتمدة ويراجع شروطها قبل التشغيل.

## القيود والقرارات

تفعيل مؤسسة البائع لا يعني اعتمادها لكل متجر. يقيد كل طلب بهوية البائع والمتجر النشط معاً. عند تبديل مساحة العمل يجب تحميل بيانات النطاق الجديد.

## تعرف على البائع قبل اختيار المنتج

افتح البائعين وابحث بالاسم. اختر البائع لقراءة وصفه وعناوينه العامة المتاحة ومجموعة منتجاته. قد يفتح البائع الذي لا يملك صفحة مخصصة قائمة تسوق مفلترة باسمه. يمكنك التصفح كضيف، بينما يتطلب الحفظ والشراء حساب العميل. لا يمثل عدد البائعين المعروض ضماناً للتوصيل.

## تدفق البيانات والنتيجة

هوية البائع + اعتماد المتجر ← مساحة عمل متاحة ← منتجات وطلبات البائع. اعتماد البائع يختلف عن مراجعة نشر المنتجات.

## عند حدوث مشكلة

راجع مساحة العمل والصلاحية وحالة السجل وأخطاء الحقول أولاً. إذا ظهرت مهلة بعد إرسال إجراء، افحص السجل وتاريخه قبل إعادة المحاولة. صعّد المشكلة مع اسم الشاشة ومعرف السجل والتوقيت؛ لا تتضمن بيانات الدخول أو أسرار الدفع.

## المراجع وحدود التحقق

كتابة إرشادية مبنية على وثائق الوحدة ومسارات الواجهات ومصدر الخادم. وجود المسار لا يثبت اختبار كل إجراء حياً. راجع [تغطية الشاشات](/ar/coverage) و[مرجع الأدلة](/ar/evidence) للمصادر والحقول. الصور توضيح لحسابات العرض بتاريخ 17 نوفمبر 2026 وليست بيانات إنتاج.
