## How to use it

Tenant operators configure Commission rules where authorized and inspect Commission records and adjustments. Vendors review their own charges and the originating order context. Use reporting to compare earned, reversed and settled values.

<SystemTour tour="feature-commission" compact />

## Restrictions and decisions

A new rule must not silently rewrite historical captured economics. Refunds and reversals need linked evidence. Vendors cannot edit their own commission to alter a settlement. Commission amount is not the same as vendor payout net.

## Data flow and outcome

Applicable rule → order commission calculation/capture → reversal or adjustment → settlement line.

## Read fees and vendor money separately

**Pre-release financial correction · 19 November 2026.** The updated calculation is under final release acceptance. The fee card shows the assessed commission after supported automatic fee reversals. Manual vendor adjustments are separate signed credits or debits; they do not change that fee or prove platform profit or a payout.

For a 100.00 sale with a 10.00 fee, the vendor balance starts at 90.00 before other effects. A 40.00 successful refund deducts 40.00 from the vendor balance even when the commission rate is zero. Any supported fee reversal is a separate credit. A manual +20.00 vendor credit does not turn a 10.00 commission into 30.00.

Order confirmation alone does not make its fee snapshot payable. The relevant seller order needs supported full funding. A newly recognized amount appears when that recognition succeeds; a late repair does not silently insert it into an already closed earlier period. Successful earlier refunds are checked before recognizing the balance.

Unknown original seller ownership or refund timing requires finance review, not a guessed full vendor credit. Settled commission history cannot be reopened, rewritten or deleted. Use a new authorized adjustment for corrections. Any supplied order/item reference must match the same store, seller, currency and original order; an intentionally unreferenced manual adjustment can still be valid.

If a manual adjustment request times out, retry the same values in the open form. An unchanged submission uses the original request key and returns the existing entry if it already posted. A correction started from a settlement uses that statement’s seller and currency, and records a link to it.

## Schedule commission changes

Open **Commissions → Commission rules**. Set the scope, currency, fee and any effective dates. The UTC start is included and the end is excluded. The list shows whether each rule is scheduled, effective, inactive or ended. To change an active dated rule, select **Schedule replacement** and choose a future UTC start. The previous rule ends when the replacement starts. Keep its scope, priority and currency for a direct replacement.

For several changes, open **Bulk rate changes** and add up to 100 rules before applying the batch. The batch saves together. If any rule is invalid or would overlap another rule in the same scope, currency and priority, review the flagged rows and resubmit the batch.

Currency-specific fees use the selected currency without conversion. A percentage rule can also add a flat fee and set a minimum. The flat fee and minimum apply once per order line. CartJoin calculates the percentage on the eligible base, adds the flat fee, applies the minimum, and caps the fee at that base. For example, 8.50% plus 2.00 on a base of 100.00 yields 10.50, or 12.00 when the minimum is 12.00.

Use **Commission tools** to preview a rate with a currency and an evaluation time in UTC. The preview uses saved effective windows and the current terms of any undated rules or fallback settings. The commission detail shows the actual terms saved with a capture. Refunds use the original captured fee.

## Download a commission statement

In the tenant dashboard, open **Commissions → Commission tools** and use the statement export. In the vendor dashboard, use **Export commission statement** on the commissions list. Choose a currency and UTC dates and, on the tenant dashboard, a vendor. The start is included and the end is excluded. Download the private CSV when it is ready. It includes opening and closing balances for the commission activity in scope, with order, adjustment and refund references where available. Use the settlement statement for the balance that includes sales and recorded payouts.

For manual adjustments, the order and commission pickers use the selected vendor and currency. Changing either clears the previous references. The adjustment ledger shows the signed effect on the vendor balance, including a credit when a refund reverses an original commission fee.

## When something goes wrong

Check workspace, permission, record state and field errors first. If an action times out, inspect the record and its history before retrying. Escalate with the screen, record identifier and time; omit passwords and payment secrets.
