## How to use it

Operators maintain code, activation dates, limits and product/category eligibility in Coupons. Customers enter the code in Cart and check the recalculated discount. Inspect usage limits when a previously valid code stops applying.

<SystemTour tour="feature-coupons" compact />

## Restrictions and decisions

The code must belong to this tenant, be active within its dates and satisfy minimum amount, usage limits and any first-order/product/category conditions. Fixed discounts cannot exceed subtotal; percentage discounts respect configured caps; free shipping affects shipping only.

## Data flow and outcome

Coupon policy → cart eligibility → computed discount → reserved/redemption lifecycle at purchase. Displayed code acceptance can change if cart contents change.

## When something goes wrong

Check workspace, permission, record state and field errors first. If an action times out, inspect the record and its history before retrying. Escalate with the screen, record identifier and time; omit passwords and payment secrets.
