## How to use it

Tenant operators maintain Attributes, then configure allowed values on a variable product. Generate or review combinations and set each variant’s SKU, price and activation. Customers select the exact combination on the product page.

<SystemTour tour="feature-attributes" compact />

## Restrictions and decisions

An attribute value is not stock by itself. Do not promise availability until the actual variant and its inventory are checked. Modifying options must not be used to change historical order snapshots.

## Data flow and outcome

Attribute → values → variant combination → SKU → inventory balance and cart line.

## When something goes wrong

Check workspace, permission, record state and field errors first. If an action times out, inspect the record and its history before retrying. Escalate with the screen, record identifier and time; omit passwords and payment secrets.
