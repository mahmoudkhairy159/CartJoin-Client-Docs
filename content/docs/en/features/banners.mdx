## How to use it

Open Banners, choose the placement, provide translated content/media and a valid destination, then set the available activation/scheduling controls. Review the actual storefront size and click destination.

<SystemTour tour="feature-banners" compact />

## Restrictions and decisions

The banner does not create the advertised discount. The linked offer must independently qualify in pricing and checkout. A disabled, future or expired placement should not be treated as a current campaign.

## Data flow and outcome

Placement + translated media + target link → storefront promotion entry → destination product/campaign validation.

## When something goes wrong

Check workspace, permission, record state and field errors first. If an action times out, inspect the record and its history before retrying. Escalate with the screen, record identifier and time; omit passwords and payment secrets.
