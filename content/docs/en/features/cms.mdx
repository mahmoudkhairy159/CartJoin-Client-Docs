## How to use it

Use CMS → Pages, Content blocks and Navigation menus. Maintain translated content, review the destination and publication options, then verify the public page or menu in the storefront. Platform users use the available moderation surface.

<SystemTour tour="feature-cms" compact />

## Restrictions and decisions

A saved draft is not necessarily published. Navigation visibility is not authorization. Avoid broken destinations and do not publish private operational information into a public content block.

## Data flow and outcome

Translated content + publication/menu configuration → storefront page and navigation rendering.

## When something goes wrong

Check workspace, permission, record state and field errors first. If an action times out, inspect the record and its history before retrying. Escalate with the screen, record identifier and time; omit passwords and payment secrets.
