## How to use it

Optional marketing has separate [choices for each store](/en/features/marketing-consent) in Account → Profile & addresses. Inbox read status and topic subscriptions never opt a customer into offers or cart reminders. Essential order, payment and security messages continue independently.

Use the bell for recent notifications and Notifications for the full list. Open the linked record, confirm its current state, and carry out the action only through that record’s permitted workflow. Customers use Account → Notifications.

In the Platform Admin dashboard, use **Extra data** when composing or editing a notification. Select **Add setting**, enter a unique key, and choose the value type. For example, use the key `url` with the text value `/orders/12`. Lists and objects expand into editable rows. In the edit form, removing the last saved row and saving clears the extra data.

## Restrictions and decisions

Account → Notifications shows when this store blocks new stock alerts. On the product page, you can cancel an alert you already set, including after a restock.

Marking read does not approve, pay or resolve the underlying record. A delayed notification may describe a state that has already changed. Following a link still requires ownership and permissions.

## Data flow and outcome

Business event → queued notification → recipient inbox → linked current record and separate business action.

## When something goes wrong

Check workspace, permission, record state and field errors first. If an action times out, inspect the record and its history before retrying. Escalate with the screen, record identifier and time; omit passwords and payment secrets.

## Development SMS delivery

The local SMS test adapter stores an encrypted message for ten minutes and does not send a real SMS. An authorized developer can inspect the local outbox; passwords, OTPs and message contents must not appear in screenshots or client documents. A local accepted delivery is not evidence that a mobile network delivered anything. Production test access is disabled; a missing real notification transport must not report a successful send.
