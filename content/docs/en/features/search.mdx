Select an option or minimum rating on **Shop**. Counts show matching products. Adjust the price slider or type an exact price, and select **In stock** to see purchasable options at the checkout location.

## How to use it

Use Shop filters for category, brand, vendor, option, price, minimum rating and stock. Shop and the search palette use the same product keyword matching. Guests can search the approved vendors in the palette or open the vendor directory. Keywords can mix Arabic and English. Matching ignores Arabic diacritics, normalizes common letter variants and searches both translations.

Tenant staff can review search queries and open **Recommendations** to list exclusions, inspect or remove pinned product pairs, and check rail performance. Creating and removing pairs requires the manage permission.

<SystemTour tour="feature-search" compact />

## Restrictions and decisions

Search stays within the current storefront and its eligible published offers. **In stock** uses the active inventory location selected for checkout. Ordinary browsing can show an out-of-stock offer. Recommendations recheck eligibility, exclusions and stock before showing a product. Delivery coverage is checked through the store's checkout.

## Data flow and outcome

Published catalog → tenant-scoped keyword and filter query → product page → cart. Search logs record the first result page for keyword searches, including searches with zero results. Open **Search analytics** in the Admin or Tenant query log to report on a UTC date range and source. The report counts Shop and product search API requests and excludes palette previews and earlier entries without a recorded source. Click statistics cover the first Shop results page when shoppers have active shopping measurement consent. Searches need 15 minutes to finish the click measurement window.

## When something goes wrong

Check workspace, permission, record state and field errors first. If an action times out, inspect the record and its history before retrying. Escalate with the screen, record identifier and time; omit passwords and payment secrets.
