---
title: "Troubleshooting and escalation"
description: "Diagnose the state before retrying."
---

| Symptom | Action |
|---|---|
| Menu missing | Check dashboard type and role; ask the access owner to review grants |
| Record not found | Check URL, ownership and workspace; do not try other tenants’ identifiers |
| Session expired | Sign in with the same account type and reopen the record |
| Field validation | Correct the named field; referenced records must belong to current scope |
| Price/stock changed | Reload cart and review variant, quantity and total |
| Payment unconfirmed | Inspect attempt, bank proof or provider event; do not trust return page |
| Timeout after financial action | Check invoice, ledger and external reference before retrying |
| Export not ready | Follow job status; queued is not completed |
| Zero metrics despite orders | Check period, metric definition and generated time |
| Vendor workspace missing | Check approved vendor-tenant link and account state |

Escalate with role, tenant, record identifier, time, steps and the visible error. Use a private support ticket for necessary evidence only; omit passwords, access tokens and full payment details.
