Routes below use the resolved tenant or the authorized platform moderation scope.

## Tenant dashboard

- `/api/tenant/v1/cms/pages` · CRUD
- `/api/tenant/v1/cms/pages/{id}` · `publish`, `archive`, `status`, `preview-link`, `revisions`, `schedule`, `media`
- `/api/tenant/v1/cms/content-blocks` · CRUD, `publish`, `revisions`, `toggle-is-active`
- `/api/tenant/v1/cms/content-block-placements/journal` · GET, PUT
- `/api/tenant/v1/cms/editor-preview` · GET
- `/api/tenant/v1/cms/content-blocks/preview-list` · GET
- `/api/tenant/v1/cms/navigation-menus` · CRUD, `publish`, `revisions`, `toggle-is-active`

## Admin dashboard

- `/api/admin/v1/cms/{pages|content-blocks|navigation-menus}` · GET
- `/api/admin/v1/cms/{resource}/{id}` · GET, `moderate`, `release`, `revisions`
- `/api/admin/v1/cms/editor-preview` · GET
- `/api/admin/v1/cms/pages/{id}/preview` · GET

## Storefront

- `/api/user/v1/cms/pages/{slug}` · GET
- `/api/user/v1/cms/content-blocks?placement=journal` · GET
- `/api/user/v1/cms/navigation-menus` · GET

## Content formats

Page states are draft `1`, published `2`, and archived `3`. The platform hold is a separate restriction. Menu link types are page `1`, category `2`, external URL `3`, label `4`, and product `5`.

| Type | Value |
| --- | --- |
| HTML | 1 |
| Text | 2 |
| Markdown | 3 |
| Image/CTA | 4 |
| Product list | 5 |
